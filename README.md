# 12 个日常 Prompt，给 AI 一份更清楚的任务

一篇使用指南，配套 12 组可复制的原创实用模板。覆盖问清问题、学习、解决问题、决策和自我认识。

依据[常用 Prompt 合集](https://mp.weixin.qq.com/s/NAdhdFrUq9-BKelqzqpwBQ)核对用途后独立写作。这里没有收录原文提示词全文，也不代表原作者的新版本。

## 公众号排版

采用「摸鱼绿」，适合提示词教程与知识整理。HTML 已通过 gzh-design 校验，ERROR 为 0，WARNING 为 0。正文无待补图片，无需另行生成配图即可使用。

下载本仓库并用浏览器打开预览 HTML，点击「复制到公众号」，再粘贴到飞书或公众号编辑器。GitHub 文件页面展示的是源码，复制按钮需要在本地预览页使用。粘贴后的平台样式仍应在正式发送前检查。
